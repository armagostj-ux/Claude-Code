# Trump Accounts Explorer

An interactive site for illustrating the benefits and long-term planning
opportunities of Trump Accounts (created by the 2025 One Big Beautiful Bill
Act, live since July 4, 2026) — built for financial-advisor client
conversations.

## What's here

- **Benefits overview** — the $1,000 seed deposit, tax-deferred index-fund
  growth, family/employer contribution limits, and automatic conversion to a
  traditional IRA at 18.
- **Compounding calculator** — adjust contributions and return assumptions to
  compare a Trump Account against a taxable brokerage account and a cash
  savings account, from birth through retirement.
- **Scenario planner** — model early-withdrawal exceptions (first home,
  education, small business) against a standard penalized withdrawal, and
  compare converting to a Roth IRA at 18 vs. holding as a traditional IRA to
  retirement.
- **Rules & timeline** — the account's life cycle from birth to age 59½+.
- **FAQ** — sourced answers on eligibility, contribution limits, investment
  rules, and withdrawal exceptions.

All figures are illustrative and use hypothetical, constant rates of return.
This is an educational tool, not tax or investment advice — see the sources
and disclaimer in the site footer.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run preview  # preview the production build
```

Built with React, TypeScript, Vite, Tailwind CSS, and Recharts.
